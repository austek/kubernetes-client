Java derives an automatic module name from a jar's filename only after stripping a trailing version matched by -(\d+(\.|$)); in these SNAPSHOT builds the version segment is "999-SNAPSHOT", where 999 is followed by "-" rather than "." or end-of-string, so the version is never stripped and derivation fails outright ("Invalid module name: '999' is not a Java identifier"). At a real release version such as 7.9.0 the version would strip cleanly and these jars would instead become filename-derived automatic modules — the defect actually reported in issue #7986 — so this baseline captures a stricter failure mode of that same root cause, not a milder one.
